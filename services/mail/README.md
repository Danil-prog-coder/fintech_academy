# mail — демо-интеграция платформы

Почтовый клиент (IMAP/SMTP) со **своими пользователями**, который подключает платформу так же, как это сделал
бы любой внешний сервис: только через открытый API `/v1` и с собственным ключом интеграции.

- Пользователь почты на платформе — `mail-user-<id>` (id из базы почты); email платформе не передаётся.
- **Проекты**: создать проект (код проекта и ссылка для сайта администратора показываются один раз), войти в проект
  админом по коду (в том числе в проект, созданный на сайте), выбрать текущий, назначить коллегам статусы по email.
- **Чат** и **«Спросить у ИИ»** в окне письма: вопросы из черновика уходят в документацию текущего проекта;
  рекомендация «письмо можно не отправлять», если ответ найден.
- **«Ответить с ИИ»** у входящего письма: каждый вопрос письма ищется в документации, черновик ответа (абзац на
  вопрос, без номеров источников) вставляется в окно ответа над цитатой. Чего в документации нет, помечено
  «[уточнить: …]»; источники и оценка — под письмом. Отправляет письмо сам пользователь кнопкой «Отправить».
- **Поддержка**: кнопка «Связаться с поддержкой», ответы специалистов приходят уведомлениями.
- **Уведомления**: события платформы читаются опросом `/v1/events` с курсором в базе — почте не нужен публичный адрес.

## Код

| Путь | Что |
|---|---|
| `backend/mail_api/api/platform.py` | проекты, статусы по email, чат, оценки, поддержка, уведомления |
| `backend/mail_api/api/mail.py` | «Спросить у ИИ» по черновику, «Ответить с ИИ» (`/mail/reply-draft`) |
| `backend/mail_api/api/mailbox.py`, `services/mailbox/` | почтовый клиент: ящики, папки, письма, вложения, отправка (защита от SSRF, очистка HTML) |
| `backend/mail_api/services/platform.py` | клиент открытого API платформы |
| `backend/mail_api/services/notifications.py` | опрос событий платформы → уведомления пользователей |
| `frontend/` | React 19 + RTK Query (FSD): почта, «Проекты», чат, колокольчик уведомлений |

## Тесты

`cd backend && .venv/bin/pytest` — почтовый клиент против локальных IMAP/SMTP-серверов и интеграция с платформой
через фейковый `/v1`. На Postgres: `E2E_DATABASE_URL=postgresql+asyncpg://…`.
