# Fintech Academy — frontend

React 19 + TypeScript + Redux Toolkit + Vite, архитектура Feature-Sliced Design.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Основные команды: `npm run check` (типы + линтеры + форматирование), `npm run build`.
Правила архитектуры и стиля кода — в [AGENTS.md](./AGENTS.md).
